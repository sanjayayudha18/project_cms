# Small Changes Log (Gemini / Antigravity)

Catatan perubahan kecil/ringan (*Small Change Dev*) yang diputuskan user tidak memerlukan alur spec penuh (`.agents/specs/`) maupun scope-driven dev (`.agents/scopes/`).
Kriteria: perubahan teks/label UI, styling CSS/padding, penambahan opsi statis, atau perubahan 1-2 file ringan tanpa perubahan skema database dan tanpa menyentuh modul finansial/auth/maker-checker.
Urutan terbaru di paling atas. Satu entri per perubahan.

Template:

```markdown
## YYYY-MM-DD — <judul singkat perubahan>
- **Objective**: tujuan perubahan / kebutuhan user
- **Scope**: daftar file yang disentuh (maksimal 1-2 file ringan)
- **Changes**: ringkasan perubahan teknis yang dilakukan
- **Verification**: automated test / lint yang dijalankan; manual browser verification: outstanding
- **Commit / PR**: <sha atau ref>
```
