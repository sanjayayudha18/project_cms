## Overview

Deliver admin add / edit / disable-enable for **users** and **vendors** on the ATM backend (port 8080, flat JSON) then the CompanyPortal-Vite screens, following the ATM backend's technical-layer layout (handler → service → repository → sqlc). Implementation is **backend-first**: sqlc queries + repositories → services (validation + audit) → HTTP handlers + route wiring → backend quality gate, then the shared Dialog primitive → users screen → vendors screen → frontend quality gate → docs. No new tables — existing `users`/`vendors` columns are reused; disable is soft-delete, never hard delete; every state-changing action writes an audit entry and applies immediately (no maker-checker).
