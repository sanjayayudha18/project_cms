Catatan untuk review

  • Satu tombol primer (merah brand) per layar: "Ajukan untuk persetujuan", "Ajukan", "Coba terapkan lagi", "Setujui". Tombol lain secondary/ghost.
  • Status batch selalu badge ikon + label, tidak memakai merah brand. "Gagal diterapkan" memakai merah rose (danger), terpisah dari merah brand.
  • Angka dan nominal memakai tabular-nums; nominal rata kanan, monospace, dengan mata uang IDR di label kolom.
  • Langkah 1 dan 2 tetap terlihat (sedikit redup) supaya pengguna bisa mengganti entitas atau file; mengganti salah satunya menghapus hasil langkah 3.
  • Badge "Dibatalkan" di Layar F adalah label tampilan untuk baris berstatus stale yang ikut dibatalkan karena baris lain gagal; baris penyebabnya berlabel "Gagal" dengan pesan error.
  • Notifikasi (bell) memakai komponen notifikasi yang sudah ada, jadi tidak digambar ulang di sini.
