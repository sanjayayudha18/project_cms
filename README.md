# CMS ATM & CIT

Cash Management System (CMS) for ATM & CIT operations.

## Overview

CMS ATM & CIT is a greenfield banking operations platform built to support end-to-end ATM cash management workflows.

The main objective of this system is to manage and control:

- vendor replenishment
- daily DSR reporting
- forecasting and scheduling
- cash count for vault and selective machine
- reconciliation against Corebanking escrow
- vendor invoice validation and approval
