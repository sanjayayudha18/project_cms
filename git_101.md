# Git 101 - Useful Commands Cheatsheet
## Setup & Configuration

```bash
git config --global user.name "Your Name"
git config --global user.email "your.email@example.com"
git config --global core.editor "code --wait"   # Set VS Code as default editor
git config --list                                  # View all config
```

## Starting a Repository

```bash
git init                        # Initialize a new repo
git clone <url>                 # Clone a remote repo
git clone <url> --branch <name> # Clone a specific branch
```

## Daily Workflow

```bash
git status                      # Check working tree status
git add <file>                  # Stage a specific file
git add .                       # Stage all changes
git commit -m "message"         # Commit with message
git commit --amend              # Amend last commit (edit message or add files)
git push                        # Push to remote
git pull                        # Fetch + merge from remote
git fetch                       # Fetch without merging
```

## Branching

```bash
git branch                      # List local branches
git branch -a                   # List all branches (local + remote)
git branch <name>               # Create new branch
git checkout <branch>           # Switch to branch
git checkout -b <name>          # Create and switch to new branch
git switch <branch>             # Modern way to switch branches
git switch -c <name>            # Modern way to create + switch
git branch -d <name>            # Delete branch (safe)
git branch -D <name>            # Force delete branch
git merge <branch>              # Merge branch into current
git rebase <branch>             # Rebase current onto branch
```

## Stashing

```bash
git stash                       # Stash uncommitted changes
git stash save "message"        # Stash with description
git stash list                  # List all stashes
git stash pop                   # Apply latest stash and remove it
git stash apply                 # Apply latest stash (keep it)
git stash drop                  # Remove latest stash
git stash clear                 # Remove all stashes
```

## Viewing History & Diffs

```bash
git log                         # Full commit history
git log --oneline               # Compact history
git log --oneline --graph       # Visual branch graph
git log --author="name"         # Filter by author
git diff                        # Unstaged changes
git diff --staged               # Staged changes
git diff <branch1>..<branch2>   # Compare branches
git show <commit>               # Show commit details
git blame <file>                # Who changed what, line by line
```

## Undoing Things

```bash
git restore <file>              # Discard changes in working dir
git restore --staged <file>     # Unstage a file
git reset --soft HEAD~1         # Undo last commit, keep changes staged
git reset --mixed HEAD~1        # Undo last commit, keep changes unstaged
git reset --hard HEAD~1         # Undo last commit, discard changes (DANGEROUS)
git revert <commit>             # Create a new commit that undoes a commit
git clean -fd                   # Remove untracked files and dirs
```

## Remote Operations

```bash
git remote -v                   # List remotes
git remote add <name> <url>     # Add a remote
git remote remove <name>        # Remove a remote
git push -u origin <branch>     # Push branch and set upstream
git push --force-with-lease     # Force push (safer than --force)
git pull --rebase               # Pull with rebase instead of merge
```

## Cherry-pick & Tags

```bash
git cherry-pick <commit>        # Apply a specific commit to current branch
git tag <name>                  # Create lightweight tag
git tag -a <name> -m "msg"      # Create annotated tag
git push --tags                 # Push all tags to remote
```

## Useful Aliases (add to .gitconfig)

```bash
git config --global alias.st "status"
git config --global alias.co "checkout"
git config --global alias.br "branch"
git config --global alias.cm "commit -m"
git config --global alias.lg "log --oneline --graph --all"
git config --global alias.unstage "restore --staged"
```

## Pro Tips
*   **Always pull before push** to avoid conflicts
*   **Use** **`--force-with-lease`** instead of `--force` to avoid overwriting others' work
*   **Commit often, push regularly** (small commits are easier to debug)
*   **Write meaningful commit messages**: `feat:`, `fix:`, `docs:`, `refactor:`, `chore:`
*   **Use** **`.gitignore`** to keep build artifacts, secrets, and IDE files out of the repo
*   **Use** **`git stash`** before switching branches with uncommitted work
*   **Rebase for clean history**, merge for preserving context
